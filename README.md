# أثر | رحمة لمحمود عزمي العمري

أثر رقمي هادئ يجمع القرآن الكريم والأذكار والدعاء، ويذكّر كل من يمر به بالدعاء للمرحوم **محمود عزمي العمري**، رحمه الله.

## المزايا
- القرآن الكريم كاملًا (114 سورة / 6236 آية).
- بحث في الآيات بالتشكيل أو بدونه.
- استماع للقرآن مع عدة قراء، ومنهم ياسر الدوسري.
- انتقال تلقائي بين الآيات والسور، تكرار، سرعة تشغيل، وآخر موضع قراءة.
- علامات محفوظة ومشاركة ونسخ.
- أذكار كثيرة مصنفة: الصباح، المساء، النوم، بعد الصلاة، الاستيقاظ، المنزل، المسجد، الطعام، الاستغفار، سيد الاستغفار، الكرب وغيرها.
- عدادات أذكار مع حفظ التقدم في LocalStorage.
- أدعية للمرحوم مع النسخ والمشاركة.
- وضع ليلي/نهاري، تصميم responsive، قائمة موبايل، حركات خفيفة، وPWA.
- تذكير علوي عند الدخول: لا تنسَ الدعاء لمحمود بالرحمة والمغفرة.

## التقنيات
HTML5 + CSS3 + JavaScript فقط، بدون Backend وبدون Framework.

## التشغيل
افتح `index.html` أو شغّل المشروع عبر Live Server.

## مصادر القرآن
النص والبيانات من Al Quran Cloud API، والصوت من مصادر Al Quran Cloud / EveryAyah بحسب القارئ.
